# 👨‍🏫 Teacher Assistant

**Teacher Assistant** is my second Python project that I am publishing on GitHub.

It is a **practice project** that I am building while learning Python. The goal is to create a simple CLI application that can help teachers manage students, attendance, and notes.

### ✨ Current Features

* Add and view students
* Manage student IDs
* Record attendance
* View attendance summaries
* Add, view, and delete notes
* Store data using JSON files

The project is still under development, and some sections are currently unfinished.

### 🤖 Built While Learning

I built this project **with the help of AI** as a learning assistant. I use AI to understand concepts, solve problems, find bugs, and learn better while building the project myself.

This is a **learning project**, so there may be mistakes or things that could be improved.

If you find a bug, have a suggestion, or see something that could be done better, **I'd be happy to hear about it!** Feel free to let me know.
